# 一、HBCloud 快速上手

## 🔑 第一步：登录并修改密码
- 使用您的 **手机号 + 初始密码** 登录（初始密码已私信发送）
- **首次登录后必须修改密码**（5分钟内完成）

1. **获取密码**
   - 检查 **薪福通私信** 获取个人账号和密码  
   - 示例消息：  
     ```
     【HBCloud 账号通知】
     您的账号：13800000001  
     初始密码：aB3dF7gH9jKm
     ```

2. **强调安全事项**  
   ```
   【重要】请务必在首次登录后立即修改初始密码！
   - 请勿将密码告知他人
   - 如果登录时遇到困难请及时联系信息中心
   - 登录后请将密码保存在安全的地方
   ```

3. **密码修改指引**  
   ```
   🔧 首次登录后修改密码步骤：
   1. 进入 HBCloud 网盘主页（http://edri.hebei/ 主页中找到 HBCloud 河北分院网盘（推荐）或使用IP登录：https://192.168.1.254/）
   2. 在登录框右下角 → 选择「修改密码」
   3. 填写：手机号、原密码（私信发送的初始密码）、新密码、确认新密码
   4. 使用新密码登录
   ```

## 📁 第二步：文件迁移操作指南

| 文件类型       | 迁移目标位置             | 操作说明 |
|----------------|--------------------------|----------|
| **个人文件**   | `公共空间 > 您的手机号目录` | 仅您本人可访问 |
| **部门文件**   | `公共空间 > 您所在部门空间目录`   | 可能需要部门领导授权成员权限 |
| **全院共享文件** | `公共空间`                | 所有员工可读 |

> ⚠️ **重要提醒**：未在1月30日前迁移的文件，将被统一归档至公共空间根目录 `/未认领文件/`，2月14日后可能被清理。
> 关于空间使用的详细操作可以查阅主页右上角 **帮助**

## 👥 第三步：部门权限设置（仅限部门领导/主管）

1. 登录后进入 **「文件浏览」** → 顶部切换至 **「部门空间」**
2. 选择您负责的部门
3. 点击右上角 **「空间权限」** → 添加成员
   - `dept`：部门管理员（默认为您自己）
   - `member`：填写本部门成员的 **手机号**（支持批量添加）
4. 保存后，成员即可访问该部门空间

> 💡 普通成员无需操作权限，只需上传、移动文件到对应部门空间即可。
